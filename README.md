# Sales Prediction using Python

## CodeAlpha Task 4

This project predicts sales based on advertising expenditure using Machine Learning.

## Dataset

The project uses an advertising dataset containing information about:

- TV advertising
- Radio advertising
- Newspaper advertising
- Sales

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Machine Learning Model

Linear Regression is used to predict sales.

## Project Steps

1. Load the dataset
2. Clean the data
3. Analyze missing values
4. Perform statistical analysis
5. Visualize advertising and sales relationships
6. Analyze correlations
7. Split the data into training and testing sets
8. Train a Linear Regression model
9. Predict sales
10. Evaluate the model
11. Analyze advertising impact
12. Predict future sales

## Evaluation Metrics

The model is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Conclusion

The project demonstrates how advertising expenditure can be used to build a machine learning model for sales prediction and analyze the relationship between different advertising channels and sales.
